# PF2e/SF2e Drag Attach

This module add an ability to attach items to other item by dragging the attachable item from an inventory to a host item's sheet.

It comes with a set of predicates that check if item can be attached based on its usage. These predicates are not the same checks that the base system uses. The base system attachment interface in unaffected.

Set the item usage to "other" to bypass the check, and attach the item with no restriction.
